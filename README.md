# ClientVibe - Qloo Hackathon Project

## Overview
ClientVibe is a B2B relationship-building agent built for the Qloo Agentic Hackathon. It takes small-talk conversational clues (music, fashion, travel) and uses Qloo's Taste Graph to recommend hyper-personalized dining options and gifts for high-value clients.

## Setup Instructions
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   streamlit run app.py
   ```
3. Open the provided `localhost` URL in your browser.

## Tech Stack
- **Frontend:** Streamlit (Python)
- **API:** Qloo Taste Graph API
